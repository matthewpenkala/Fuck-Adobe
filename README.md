# Fuck-Adobe
<!-- repo-title:end -->

**In this repo,** [**I**\*](#ai-authorship) **upload stuff that these bean-counting muppets couldn’t be arsed to fix.**

Mostly [After Effects expressions](./Expressions). A few of them:

- **[Exponential Scale](./Expressions/expScalePreserveEase.md)**: drive exponential scaling with the easing on your existing keyframes.
- **[Continuous Groups](./Expressions/continuousGroups.md)**: ease through several keyframes as one move.
- **[Relative Mask Parenting](./Expressions/maskPathRelativeParent.md)**: move a mask with another layer without parenting the footage along with it.
- **[Looping Wiggle](./Expressions/loopWiggle.md)**: make a wiggle loop seamlessly.
- **[CC Lens Normalization](./Expressions/ccLensPerceptualNormalize.md)**: make changes to CC Lens Size feel more even, especially near zero.
- **[Twixtor Finite Stop](./Expressions/twixtorSpeedFiniteStop.md)**: ease Twixtor into and out of a freeze, with less of the slow crawl at the end.

Setup and caveats are in each file.

Also in here: [JSX scripts](./JSX-Plugins), [Simple Fill](./Effects), and [keyboard shortcuts](./Keyboard-Shortcuts).
